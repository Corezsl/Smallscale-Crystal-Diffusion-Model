# Changelog

## 0.1.0

- Initial public research scaffold for a crystal diffusion model.
- Added forward diffusion utilities for lattice, fractional coordinate, and atom-latent variables.
- Added crystal dataset conversion from Pymatgen `Structure` objects.
- Added training, generation, and evaluation helper scripts.
- Added basic project documentation and packaging metadata.
- Added a Streamlit prototyping interface.
- Added synthetic crystal dataset utilities and configuration loading.
- Added CI workflow and linting support.
